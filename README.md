Chaque bulletin couvre les axes du JD BnL :

- **Infrastructure souveraine** — MeluXina-AI, AI Factory, CTIE
- **Écosystème bibliothèques** — AI4LAM, LIBER, Impresso, C²DH
- **Réglementation** — EU AI Act, RGPD, gouvernance IA
- **Modèles open source** — Qwen, PaddleOCR, OlmOCR, benchmarks
